# Perataan dan Pengurutan Matriks

## Deskripsi

Diberikan sebuah array dua dimensi berisi bilangan bulat.
Setiap baris dapat memiliki panjang yang berbeda-beda, dan beberapa baris dapat kosong.

Tugas Anda adalah:

1. Menggabungkan seluruh elemen dalam array dua dimensi tersebut menjadi satu array satu dimensi (flatten).
2. Mengurutkan seluruh elemen tersebut secara menaik (ascending).
3. Mengembalikan hasil akhir dalam bentuk array satu dimensi.

---

## Format Masukan

Sebuah array dua dimensi `A` dengan ketentuan:

- Banyak baris: ( N )
- Setiap baris berisi bilangan bulat
- Baris dapat kosong

---

## Format Keluaran

Semua barisan bilangan bulat secara menaik (descending)

---


## Contoh 1

**Input**

```java
{{3,2,1},{4,6,5},{},{9,7,8}}
```

**Output**

```java
1 2 3 4 5 6 7 8 9
```

---

## Contoh 2

**Input**

```java
{{10},{3,5,7},{2,8}}
```

**Output**

```java
2 3 5 7 8 10
```
